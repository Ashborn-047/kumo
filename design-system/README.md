# ☁️ Kumo Design System

This is the dedicated, standalone design system folder for Kumo.

## 📂 Contents

- **`index.html`**: The complete design system viewer. Open directly in your browser by double-clicking or visiting `http://localhost:3000/design`.
- **`tokens.css`**: Pure CSS token variables (`--sky`, `--butter`, `--mint`, `--r-lg`, etc.).
- **`kumo.css`**: Ready-to-use component stylesheet (`.kumo-card`, `.kumo-dock`, `.kumo-btn`, `.kumo-glass`).
- **`kumo.js`**: JavaScript helpers (theme switching, color palettes).

## 🚀 Quick Start

To use the design system in any HTML or CSS file:

```html
<link rel="stylesheet" href="./design-system/kumo.css">
```

Or in CSS:
```css
@import "../design-system/tokens.css";
```
